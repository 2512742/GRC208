# Deliverables: what goes into each E-Campus field

Every member submits individually on E-Campus (GRC208, Capstone Project, attempt 1 of 1). Some fields are **identical for all 17 members**: these files live with the workstream that owns them (report in WS4, slides, abstract and video in WS5). Other fields are **personal**: each member's `members/<NN-name>/submission.md` inside their workstream folder.

## 1. Portal field map

| E-Campus field (in portal order) | Shared or personal | Source in this folder | Format the portal accepts |
|---|---|---|---|
| Research / project abstract | Shared (same text for everyone, also in the PDF) | `WS5-presentation/abstract.md` | Rich text, so paste the text (about 200 to 300 words) |
| Full project documentation (PDF) | Shared | `WS4-documentation/report/GRC208_Group1_Project_Documentation.pdf` | PDF, max 64 MB |
| Additional information / your contribution | **Personal** | `WS<n>-<workstream>/members/<NN-name>/submission.md` §1 | Rich text |
| Presentation slides | Shared | `WS5-presentation/slides/GRC208_Group1_Slides.pdf` (and the `.pptx` source) | PDF, PowerPoint or OpenDocument |
| Demonstration video link | Shared | `WS5-presentation/video/demo-video-link.md` | HTTPS link only, never the video file |
| AI-use declaration (checkbox, tools used, how you used them) | **Personal** | `WS<n>-<workstream>/members/<NN-name>/submission.md` §2 | Checkbox and text |

The source code link is not a portal field. It goes inside the PDF (Abstract and project links table), and the README there carries the installation steps and demo accounts.

## 2. Folder layout

Each workstream folder (`WS1-development` to `WS5-presentation`) holds its own work and its members' `members/<NN-name>/submission.md`. See the repository `README.md` for the full map.

## 3. Freeze order (do not submit before everything is frozen)

1. **12 Dec:** report PDF, slides and video link frozen. After that, file names and contents do not change. If anything must change, WS6 tells everyone before anyone submits.
2. **12 Dec:** every member fills in `submission.md`. WS6 checks it against report section 6.2 and `docs/ai-use-log.md`.
3. **13 to 14 Dec:** each member saves a draft (free), reviews the saved evidence, then selects **Final submit** (NGN 1,000 wallet charge) and records the receipt in their `submission.md` §4.
