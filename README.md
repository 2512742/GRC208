## How to add your work (no coding needed)

1. Ask Ocen to add your GitHub account as a collaborator (send your username).
2. On GitHub, open **your workstream folder**, then **Add file → Upload files** (or open a file and click the pencil to edit it).
3. Write a short message saying what you added, choose **Create a new branch**, and open a pull request. Your lead or Ocen merges it.

Every upload is recorded under your name, which is the group's evidence of who did what (brief deliverable 6). Developers follow [`CONTRIBUTING.md`](CONTRIBUTING.md).

**Never upload** passwords, tokens, `.env` files or real personal data. All data in this project is fictional.
